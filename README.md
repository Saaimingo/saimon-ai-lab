# Saimon AI Lab

Este repositório reúne pesquisas, hipóteses, documentos e projetos pessoais relacionados a inteligência artificial local, agentes, memória evolutiva, arquitetura cognitiva, estudos em ADS, laboratório de hardware e integração com ferramentas reais.

O objetivo não é apenas guardar ideias soltas.

O objetivo é transformar conversas, descobertas e hipóteses em patrimônio técnico organizado.

## Projetos principais

* Odysseus + SCR
* Laboratório de IA Local
* ADS Estudos
* Hardware GPU Lab

## Filosofia

Modelos podem mudar.

Ferramentas podem mudar.

O patrimônio acumulado precisa permanecer.
