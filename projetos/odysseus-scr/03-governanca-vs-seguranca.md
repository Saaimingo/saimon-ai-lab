# Governança vs Segurança

Durante as discussões, ficou claro que governança e segurança não são a mesma coisa.

## Segurança

Segurança é blindagem.

Ela responde:

* O que o sistema não pode acessar?
* Como evitar invasão?
* Como impedir execução remota indevida?
* Como evitar prompt injection?
* Como proteger ferramentas perigosas?

## Governança

Governança, ou regimento interno, define como o sistema deve funcionar.

Ela responde:

* Quando buscar memória?
* Quando buscar na web?
* Quando pedir autorização humana?
* Quando preservar conhecimento?
* Como conduzir modelos menores pelo caminho correto?

## Hipótese

Modelos menores podem falhar não por falta de conhecimento, mas por não saberem qual caminho seguir.

A governança pode forçar fluxos obrigatórios.

Exemplo:

Se o usuário perguntar “o que você sabe sobre mim?”, o sistema deve obrigatoriamente consultar a memória antes de responder.
