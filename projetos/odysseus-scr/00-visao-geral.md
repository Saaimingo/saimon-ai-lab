# Visão Geral

A hipótese inicial do projeto era construir uma arquitetura cognitiva ampla.

Após análise do Odysseus, a hipótese foi reduzida.

O Odysseus já possui muitas capacidades que inicialmente imaginávamos precisar construir:

* Agentes
* Multi-modelos
* Memória
* RAG
* ChromaDB
* Ferramentas
* MCP
* Scheduler
* Integrações
* Telegram
* WhatsApp
* Automação
* Pesquisa Web

A hipótese atual é:

O Odysseus não precisa ser substituído.

Ele precisa ser observado, compreendido e talvez futuramente ampliado com uma camada leve de memória evolutiva e governança.

## Ideia central

O SCR deve ser uma extensão, não uma arquitetura paralela.
