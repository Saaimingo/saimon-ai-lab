# Odysseus + SCR

Este diretório reúne a pesquisa sobre o uso do Odysseus como fundação para uma camada chamada provisoriamente de SCR.

O SCR não deve ser entendido como um novo sistema independente.

A hipótese atual é que o Odysseus já fornece a maior parte da infraestrutura operacional necessária.

O foco passa a ser estudar como adicionar, futuramente, uma camada de:

* Memória Evolutiva
* Governança interna
* Segurança reforçada
* Classificação de conhecimento
* Genealogia cognitiva
* Rastreabilidade da descoberta

Sem alterar o núcleo do Odysseus neste momento.

## Estado atual

A decisão atual é observar o Odysseus por algumas semanas antes de propor alterações, pois o projeto ainda está em rápida evolução.
